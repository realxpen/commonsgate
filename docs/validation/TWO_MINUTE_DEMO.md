# CommonsGate v0.2 — 2-minute demo recording playbook

**This is a recording plan, not a produced video.** Use a local screen recorder (for example OBS or your operating system's built-in recorder). Show only the fictional lab; do not record browser notifications, real email, personal documents or a live call with a reviewer.

| Time | Show | Suggested voiceover |
| --- | --- | --- |
| 0:00–0:15 | Local app title and disclaimer | "CommonsGate is an independent synthetic-data demo about enforcing individual permissions and community decisions." |
| 0:15–0:45 | Select Allow and click Run | "All four checks pass: policy, community review, individual permission and steward approval. The gateway releases only a fabricated aggregate." |
| 0:45–1:15 | Select Community veto and click Run | "A reviewer vetoes the request, so access is denied even though other checks pass." |
| 1:15–1:45 | Select Permission withdrawn and click Run | "Access works initially. When a fictional participant withdraws permission, the same grant no longer works for later access. This cannot undo past disclosures or AI training." |
| 1:45–2:00 | Open /review.html and display disclaimer | "Version 0.2 adds a local review worksheet to challenge whether the governance rules make sense. Feedback is exported on-device, not sent to a server. Real community validation is still pending." |

## Recording checklist
- At 1280×720 or higher, zoom browser so controls and reason codes are readable.
- Disable desktop notifications and hide personal tabs.
- Run \`npm start\`, not a public deployment.
- Show actual allow / deny / revoke results, not fabricated screenshots of user feedback.
- End by stating local, fictional, no Mozilla/SRHIN endorsement, no real health records.
- Never present this script as a completed video or an evaluated pilot.

A simple voiceover with 5 screen cuts is sufficient. Keep a copy of the final video private until you've reviewed it for sensitive material and misleading claims.
