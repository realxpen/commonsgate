# Contributing

CommonsGate is an **unvalidated public-interest research prototype**. Feedback on engineering correctness, accessibility, documentation and governance assumptions is welcome.

1. Reproduce the issue using `npm test` or `npm start` with synthetic fixtures.
2. Propose small changes with corresponding unit/HTTP tests.
3. Do not upload any real mental-health information, real consent forms, user identifiers or credentials.
4. Describe any security limitations frankly; do not present this as clinical, legal or privacy-compliant software.
5. Do not imply Mozilla Foundation or SRHIN has approved or adopted a contribution.

Community governance and health-data requirements must be shaped with the people affected by those decisions before production use.
